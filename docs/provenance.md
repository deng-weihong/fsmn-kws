# 实现来源

**简体中文** | [English](provenance.en.md)

本运行库从名为 `fsmn_lab` 的本地实验实现中提取。`SOURCE_PROVENANCE.json` 记录了原始源码哈希及提取时的修改。迁移通过回归测试保持数值行为，没有更换处理算法。

## 兼容性与参数

本运行库实现 Miya 的固定默认处理链路，通过逐阶段输出和内部状态对照验证数值行为。参考运行库为 `py_sound_connect 0.2.1` Linux x86_64，固定 SHA256 为：

```text
ea564494b80c02f32197539f25acd71bba3d07ccb5725d12958b9debf9ee2dd1
```

运行时不链接或加载官方共享库；源码树不包含官方二进制或私人录音。

仓库中的 `src/frontend/defaults.json` 保留高通和六相 PPFbank 的精确默认参数，`coefficients.h` 固定其二进制 FP32 数值，使构建无需 Python。模型参数仍是单独的上游训练资源。

KissFFT 使用未修改的公开源码。WebRTC 公开数字 AGC 根据观察到的默认状态行为进行了适配。选取的 musl / Arm 数学文件用于保持宿主机与目标设备 C 库之间 FP32 幂运算的舍入一致。各依赖的来源和修改记录保存在 `third_party` 下。

模型卡不能确定官方运行库的使用条款，也不能确定兼容实现及默认系数的再分发权利。

兼容实现和默认系数的再分发边界需根据适用的上游条款单独核实。本项目 Apache 许可证仅适用于作者有权许可的贡献，不会额外授予上游运行库、模型或第三方作品超出其自身许可证范围的权利。
